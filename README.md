# Make Huawei Great Again

A personal, owner-authorized research project about Huawei phone customization, rooting, bootloader status, and device restrictions. The project is intended for phones owned by the maintainer or devices they have explicit permission to test.

## Scope and safety

- Document device models, regional variants, firmware versions, and publicly available manufacturer information.
- Prefer official support resources and reversible, well-understood changes.
- Explain risks before any modification: data loss, reduced security, warranty impact, instability, and possible device failure.
- Do not use this project to access another person's device or data, defeat an organization's controls, or distribute malware or tools for unauthorized access.
- Back up important data and verify instructions against the exact device and firmware before proceeding.

This repository is a research and documentation project. It does not currently include rooting, jailbreak, bootloader-unlock, or restriction-bypass procedures. Device ownership makes testing authorized, but does not remove the technical risks or applicable legal and warranty conditions.

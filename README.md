# Make Huawei Great Again — Nova Phone Field Guide

A polished, responsive, fan-made showcase for Huawei nova phones, starting with the nova 9 SE and the requested nova 15 Max name. Built as a lightweight static site with plain HTML, CSS and JavaScript—no build step or dependencies required.

## Preview locally

Open `index.html` in a browser, or serve this directory with any static web server. For example:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## What's inside

- Editorial-style landing page with custom CSS phone illustrations.
- Responsive product cards and a comparison table.
- Expandable nova 9 SE spec sections.
- Buyer checklist covering regional variants, app compatibility, charging and support.
- Source links and clear uncertainty labels for the requested nova 15 Max.

## Accuracy notes

This is an independent fan project, not affiliated with or endorsed by Huawei. The nova 9 SE specifications are presented as general reference points and may vary by market. The page links to Huawei's regional nova 9 SE specifications and advises readers to verify their local variant.

No official Huawei announcement or specification sheet for a "nova 15 Max" was verified while preparing this page. Its specifications are deliberately marked **not confirmed** rather than guessed. Update that section only when reliable official information is available.
